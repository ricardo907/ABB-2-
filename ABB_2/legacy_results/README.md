# 旧结果归档

这里保留优化前的标签、预测结果和模型权重，供核对；它们不是优化版的默认输出。

- 旧 `synchronized.csv` 和 `train_labels.csv` 与重新按视频时间同步的 202 行训练标签完全一致。
- 旧 `test_labels.csv` 按 Excel 行号配对视频帧。视频是 24 fps，Excel 是 250 Hz；重新按时间对齐后，218 行中有 217 行的角度值发生变化，最大单轴差约 1.583732 rad。
- 旧 `Exp002_prediction_result.csv` 基于错误的测试真值，原 MAE 0.218219 rad 无效。将其中同一组预测值与更正后的测试标签比较，MAE 为 0.503398 rad。这仍不能证明模型泛化能力。
- 旧 `robot_angle_cnn.pth` 的训练/验证方法存在同视频随机帧混用问题；保留供审计，不作为优化版模型发布。

优化版的 `test_cnn.py` 需要先运行 `train_cnn.py` 生成新权重。当前仅验证训练和测试流程可运行，未提供经过独立视频验证的模型。
